# Ollama Notes

Ollama lets me run AI models on my own HP laptop — no internet needed, private, free.

- Official site/repo: https://github.com/ollama/ollama
- Installed on: my HP laptop (Windows 10)

## Model I run
- DeepSeek-R1 1.5B — command: `ollama run deepseek-r1:1.5b`

## Commands I know
- `ollama run deepseek-r1:1.5b` — start chatting with the model
- `ollama list` — see my models
- `/bye` — exit the chat

## My notes
- Small model = fast on my laptop, good for practice questions and drafts.
- Works offline, so my words stay on my own computer.
